1. Aspect Théorique de l’ANOVA à un facteur (ANOVA 1)

L’Analyse de la Variance (ANOVA 1) est une méthode statistique utilisée pour comparer les moyennes de trois groupes indépendants ou plus sur une variable quantitative continue.

Hypothèses Statistiques

Le test repose sur l’évaluation de deux hypothèses : * Hypothèse Nulle (\(H_0\)) : Toutes les moyennes des groupes sont égales (\(\mu_1 = \mu_2 = \dots = \mu_k\)). * Hypothèse Alternative (\(H_1\)) : Au moins une paire de moyennes présente une différence statistiquement significative.

Logique du Test F

L’ANOVA décompose la variabilité totale des données en deux parties : 1. La variance inter-groupes (Between) : Variabilité due aux différences entre les moyennes des groupes. 2. La variance intra-groupes (Within / Résiduelle) : Variabilité naturelle ou erreur de mesure au sein de chaque groupe.

La statistique de test \(F\) est le rapport : \[F = \frac{\text{Variance Inter-groupes}}{\text{Variance Intra-groupes}}\]

NotePrincipe clé du Test F

Un ratio \(F\) significativement supérieur à 1 indique que la variabilité entre les groupes est trop grande pour être due au simple hasard, rejetant ainsi \(H_0\).

Conditions d’application

  • Indépendance des observations.
  • Normalité des résidus dans chaque groupe.
  • Homogénéité des variances (Homoscédasticité).

3. Logique et Utilité des Tests Post-Hoc

Lorsque l’ANOVA globale est significative, elle nous indique qu’au moins un groupe est différent des autres, mais elle ne précise pas lesquels.

ImportantPourquoi éviter les tests t classiques successifs ?

Faire de simples tests \(t\) de Student entre toutes les paires possibles accumule le risque d’erreur de type I (faux positifs). C’est le phénomène d’inflation de l’erreur globale (family-wise error rate). Les tests post-hoc ajustent les p-values pour maintenir ce risque global strictement au seuil choisi (généralement \(5\%\)).

📖 Interprétation des résultats (Données initiales)

4.1 Décoder le Test HSD de Tukey

  • Où regarder ? Concentrez-vous sur la dernière colonne nommée p adj (p-value ajustée).
  • Analyse avec les données de base : La ligne G2-G1 montre une valeur p adj de 0.022 (< 0.05), le groupe G2 est donc significativement différent du groupe G1. En revanche, la ligne G3-G2 affiche une valeur de 1.000, indiquant que leurs moyennes estimées sont statistiquement indiscernables.

4.2 Décoder le Test de Bonferroni

  • Où regarder ? Le résultat s’affiche sous forme de matrice (tableau croisé). Les valeurs à l’intérieur de la matrice sont directement les p-values ajustées.
  • Analyse avec les données de base : À l’intersection de la colonne G1 et de la ligne G2, vous observerez la valeur 0.038 (< 0.05), confirmant de manière très stricte la différence significative.

4.3 Décoder le Test de Dunnett

  • Où regarder ? Regardez la colonne finale nommée p.value.
  • Analyse avec les données de base : La ligne G2 - G1 teste uniquement si le groupe de traitement (G2) est différent de votre témoin de référence (G1). La p-value associée est de 0.019 (< 0.05), vous pouvez donc conclure avec certitude que le traitement G2 produit un résultat significativement différent du groupe témoin.
  • Remarque : Il n’y a pas de ligne G3 - G2, car Dunnett exclut judicieusement les comparaisons inutiles entre les traitements eux-mêmes pour se focaliser sur l’effet face au contrôle.
